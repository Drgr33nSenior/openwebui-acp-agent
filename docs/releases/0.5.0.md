# Open WebUI ACP Agent 0.5.0

An unofficial coding agent for JetBrains and other compatible ACP clients.

## Changes

- Approved static previews let the agent open frontend files in the configured
  browser, exercise controls and inspect results. Previews use an explicit file
  list, expire automatically and close on cancellation or turn completion.
- Runtime guidance follows the tools available in each session. It asks the
  agent to run applications, test failure cases, check browser interactions and
  consult current documentation when the corresponding tools are available.
- Full-file edit guidance and stale-content errors explain how to preserve the
  complete file, including its final newline.

## Install

Use Node.js 26 LTS and npm on macOS or Linux:

```sh
npm install --global https://github.com/Drgr33nSenior/openwebui-acp-agent/releases/download/v0.5.0/openwebui-acp-agent-0.5.0.tgz
```

Use the package attached to the GitHub release. `SHA256SUMS` verifies that package.
No npm account is needed. See [setup](../../README.md) and
[browser configuration](../browser.md).

## Scope and verification

Static previews support HTML/CSS/JavaScript and built frontend output. They do
not run framework servers, backend APIs or hot reload. Browser MCP remains
optional and its existing approvals still apply. The command sandbox is
unchanged. Local processes can read the explicitly approved preview files.

The real Chromium test passed creation, navigation, Start, score, Restart and
shutdown through the ACP loop with deterministic inference. The live-model
play-through retest was blocked by backend HTTP 503 responses; it remains
unverified. See [verification results](../verification.md) for test scope.

Native Windows remains unsupported. ACP registry inclusion and npm publication
are separate from this GitHub release. No migration of credentials or saved
sessions is required.
