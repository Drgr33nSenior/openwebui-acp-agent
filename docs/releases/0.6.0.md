# Open WebUI ACP Agent 0.6.0

An unofficial coding agent for JetBrains and other compatible ACP clients.
This release includes the changes merged since 0.5.0.

## Editing and verification

- `edit_file` applies targeted text replacements with full diffs, stale-content
  checks, checkpoints, undo and automatic verification. Edit notifications include
  the file and first changed line for clients that display locations.
- File reads use numbered pages. Search supports directory and glob filters,
  bounded results and a count of omitted matches. File listings skip generated
  environments and build output by default and support subdirectory browsing.
- Tool errors identify missing or invalid arguments. Guidance favors small edits,
  and a bounded reminder asks for a check after code changes when none was tried.
- IDE diagnostics report an unavailable bridge and have configurable time and
  output limits. Existing permissions still apply.

## Context and long sessions

- Older tool results and large edit arguments can be cleared from model context
  before compaction. The saved transcript retains them, subject to its storage
  limits. Retained tool calls keep their IDs and results; actions are not replayed.
- Compaction checks the usable input budget before coding requests and corrected
  replies. Summary requests have a bounded output allowance and use a lower
  advertised reasoning level when available. Failures explain their cause.
- The context indicator excludes reasoning tokens that are not sent back in the
  next request. Supported `xhigh` requests receive a bounded output allowance.
  Context notices no longer split buffered reply text or repeat within a turn.
- Saved sessions allow larger transcripts and reduce older saved content with a
  visible notice when necessary. The live conversation is retained.
- Full undo storage evicts the oldest checkpoints with a notice instead of
  blocking edits. Rewind refuses file restoration when the required history is
  no longer available.

## Session controls

- Ask, Plan, Code and YOLO appear in the Mode selector and ACP v1 session modes.
  YOLO still needs explicit session confirmation and respects administrator rules.
  Older permission IDs remembered by JetBrains remain compatible.
- Model selection uses Open WebUI display names and declared reasoning defaults.
- Session resume and close are supported. Loading a session replays recorded tool
  outcomes without executing them. `/rewind` can restore agent edits from earlier
  turns; `--keep-files` changes only the conversation.
- Steer mode adds messages to the active turn at a safe boundary when the client
  can send while busy. Background jobs show bounded progress and completion status.

## Install

Use Node.js 26 LTS and npm on macOS or Linux:

```sh
npm install --global https://github.com/Drgr33nSenior/openwebui-acp-agent/releases/download/v0.6.0/openwebui-acp-agent-0.6.0.tgz
```

Use the package attached to the GitHub release; `SHA256SUMS` verifies it.
No npm account is needed. Existing configuration and credentials stay in their
current locations. Keep the previous installation for rollback and reconnect the
IDE after updating its launch path. See [setup](../../README.md),
[session controls](../sessions.md), [tools](../tools.md) and
[upgrade and rollback](../migration.md).

## Scope and verification

The protocol remains stable ACP v1. Native Windows is unsupported. Browser MCP
and Open WebUI server tasks remain optional and separately approved. ACP registry
inclusion and npm publication are separate from this GitHub release.

The [verification record](../verification.md) distinguishes automated tests from
live backend and IDE acceptance. Client UI support and provider behavior still
require testing with the versions in use.
